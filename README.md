# 个人知识库

这是一个面向个人使用、便于 AI 稳定维护的简化 Obsidian 知识库 模板。

## 开始使用

1. 解压整个文件夹。
2. 在 Obsidian 中选择“打开文件夹作为仓库”，选择 `个人知识库` 文件夹。
3. 先阅读根目录的 `AGENTS.md`；处理 Wiki 时还要阅读 `wiki/AI知识管理员手册.md`。
4. 新建项目时，复制 `Templates/项目模板`，粘贴到 `Project` 并重命名。

## 目录约定

- `Project`：正在进行的项目。
- `wiki`：整理后、值得长期保存的知识，包含索引、日志、来源账本和 AI 维护手册。
- `raw`：原始资料，尽量保留原件。
- `工作流`：资料加工和重复性工作的步骤。
- `Templates`：新建文件时使用的模板。
- `归档`：已经结束的项目和不再活跃的内容。

## 使用原则

先搜索，再创建；能更新旧文件就不新建重复文件；raw 原件不可变；Wiki 录入、查询和体检遵循 `wiki/AI知识管理员手册.md`；AI 每次操作后汇报实际变更。
