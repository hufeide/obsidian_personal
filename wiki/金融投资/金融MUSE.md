# 金融MUSE

> 金融 MUSE 是一个面向金融研究、盯盘与交易决策的大模型智能体系统设计构想：以主 orchestrator 协调多专家 agent 与 Skill，围绕「做研究、盯盘、做决策」组织可自定义的工作流。

## 资料来源

- 原始素材：`E:/面试/金融MUSE.docx`（提取稿：`raw/金融MUSE.md`）
- 素材为个人笔记，未标注作者与日期；内容为作者的设计构想，非已验证的实现事实。

## 核心价值

素材将系统价值归纳为三个场景：

- **做研究**：宏观行业研究、推演。
- **盯盘**：（1）日内盯盘；（2）公告、最新新闻、数据解读；（3）订阅事件。
- **做决策**：买卖（长期、短期）。

## 大模型技术

素材列出的技术要点：

- 对话
- 周期执行
- 轮询触发

## 实现方式

- **主 orchestrator**：整体协调。
- **多专家 agent 待命**：以系统角色形式存在，配合 Skill 技能。
- **数据**：背后是特色指标和模型。
- **用户记忆**：hooks、持仓、自选等。
- **进化**：进化 agent，对技能进行调整。
- **后台**：定义不同模型。

## 用户交互

1. `@经济学家`：直接召唤专家角色。
2. 用户不知道怎么办时：通过路由、展示面板、工作流引导。
3. 可以自定义工作流。

## 案例

### 工作流定制

股价异动 → 市场监测专家报告 → 个股研究专家开工 → 结果推送到手机。

步骤拆解：

1. 异动
2. 研究：宏观、基本面、估值、一致预期
3. 之后跟踪：解禁

### 研报撰写

订阅会议 → 转录 → 分析 → 内部模板和研报 → 生成计划（数据、分析、撰写）→ 报告。

### 宏观

发布跟踪 → 预期差 → 推导（宏观图谱）。

### 组合

组合风险分析、智能推送。
